Strike a gong every time Stripe pays you.

An open-source webhook that celebrates each sale in Discord, Slack, your Mac menu bar and a browser tab on the spare monitor. It also watches your MRR and counts how many days in a row it went up.

How it works

1

Add a Stripe webhook

Point it at your server and pick three events. Signatures are verified with Web Crypto, with no Stripe SDK.

2

Paste your channel URLs

A Discord or Slack webhook, an ntfy topic for your phone, and optionally X for milestones.

3

Hear the gong

Bigger sales ring louder. Retries never double-announce, and customer emails are masked by default.

Funny where it should be

Milestones

First sale, the 100th sale, MRR crossing $1k, a 30-day streak. Each fires once, and they are the posts worth sharing.

Message modes

Calm, indie hacker, or old-school broker, with 10+ lines per tier. Add your own in one file.

Sad gong

Refunds and cancellations, in a muted tone and in private channels only. Off by default.

AI one-liners

Optional. The model sees the amount and the size of the sale. It never sees a customer.

Honest by design

  • MRR is computed from your active subscriptions with a restricted, read-only Stripe key. The day streak counts real days where it went up, and a dip breaks it.
  • Zero runtime dependencies. One handler that runs on Cloudflare Workers, Node, Docker, Bun and Deno.
  • Customer-controlled text can never ping @everyone or inject Slack links, and public posts never contain customer data.
  • MIT licensed. Self-hosted, so your revenue numbers stay yours.

Quick start

git clone https://github.com/VincentShipsIt/mrrgong.dev
cd mrrgong.dev && npm install
npx wrangler secret put STRIPE_WEBHOOK_SECRET
npx wrangler secret put DISCORD_WEBHOOK_URL
npx wrangler deploy

# or run it locally and hear it
cp .env.example .env && npm run dev
npm run simulate 49
